## 🚀 Cómo Usar Este Repositorio

### Requisitos
- Node.js >= 16
- npm o yarn
- Git

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/NatanaelHA/Portafolio.git

# Navegar al directorio
cd Portafolio

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```
